# debug-loop：排错四步循环

## 步骤
1. **复现**：先跑出同样的错误，拿到完整报错信息。不复现不动手。
2. **最小失败用例**：在 test_retrieve.py（或新测试文件）加一个用例，让它在修复前失败。如果错误在 faq_demo.py 主路径，先想能否下沉成可测的纯函数。
3. **修**：只改让该用例通过的最少代码。不顺手重构、不"顺便"改别的。
4. **回归**：跑 `python scripts/gate_ready.py`（或至少全量相关测试），确认新用例从红变绿且无回归。
   - 测试仍红时**禁止**声称「已修好」。

## 禁止
- 没复现就猜着改
- 修完不跑门禁就说好了
- 一个循环里修两个 bug（另开一轮）
