# pr-draft：改动说明三段式

## 步骤
1. `git diff` 看本次全部改动（staged + unstaged）
2. 用中文起草，格式固定：

```
<一句话标题，动词开头>

改了什么：<文件 + 行为变化，只列事实>
为什么：<对应 docs/ 里哪条需求/用例，或修的什么问题>
怎么验证：<具体命令 + 预期输出>
```

3. 若改动跨多个不相关主题，拆成多个 commit，分别起草

## 禁止
- 标题不写"update/fix"这种空话，要写行为变化
- 验证步骤不许写"已测试"而不给命令
