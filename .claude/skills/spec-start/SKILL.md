# spec-start：一句话需求 → 规格三件套

## 输入
用户的一句话需求（$ARGUMENTS 或对话中的需求描述）。

## 步骤
1. 把需求改写成一句话问题陈述（谁、什么场景、什么痛点）
2. 生成 `docs/prd.md`：用户、场景、要解决的问题、非目标、成功标准
3. 生成 `docs/spec.md`：接口、行为规则、验收用例表（**必须含至少 1 个失败态**）、System Ready 清单
4. 生成 `docs/tasks.md`：每条任务 = 动词 + 产物 + 验证命令
5. 让用户确认后再动代码

## 输出
三份文档写入 docs/，向用户复述一句话需求 + 非目标，请他签字确认。

## 禁止
- 不写代码（本 skill 只出规格）
- 验收用例表里不许漏失败态
- 不扩大范围：用户没提的一律进 docs/backlog.md
