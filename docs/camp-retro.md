## 2. 产品资产（商业向）

**卖什么**：广州公积金政策快问。缴存职工/中介 30 秒查「能贷多少」，回答带出处。

- **用户**：小企业/中介给员工用，按次计费，不自建知识库。
- **收什么钱**：新用户赠 3 次；续包 10 次 / 9.9 元（**测试支付**）。
- **闭环做到哪**：落地文案 → 注册赠次 → 问答扣次 → 墙 → 取消/失败不发货 → 成功 +10 次 → 后台账本。命令：`python demo_saas.py`。
- **诚实口径**：这是验证闭环，**不是已盈利**。无 Web、无真支付、无公开 URL。
- **成本**：约 0.02 元/次（flash live）；mock 演示 0；破产开关 `GJJ_KILL_SWITCH=1`。见 `docs/spec-saas.md`。
- **下一月（营外）**：不把 CLI 伪装成已上线产品；优先把公约试行到所在团队（见 camp-goals「30 天后」）。

修图 SaaS 原作业：**放弃 Web/修图**，用政策问答 CLI 打通同一条故事。
