# 什么情况必须转人工

> Day8 / L7 · 公积金智能客服值守政策（模拟工单）

## 立即转人工（写 ticket，返回 ticket_id）

1. **用户明确要求**：含「投诉、举报、人工、转人工、骗子」等。
2. **意图无法归类**：不像查政策、也不像查贷款进度（`other`）。
3. **低置信拒答后用户坚持**（本期 CLI 未做多轮；规则先登记，后续接会话层）。

## 不转人工、走自动路径

| 情况 | 路径 |
|------|------|
| 政策咨询且 FAQ 能检索 | RAG + 来源引用 |
| 问「我的贷款/申请进度」且 token 有效 | 只读 Tool 查 `data/orders.json` |
| 无关问题 / FAQ 无匹配 | 明确拒答，**禁止编造** |

## 必须先鉴权

- 查贷款进度 **必须** 带有效 token（作业：`demo-user-1` → 用户 U001）。
- 无效或缺失 token：返回 unauthorized，**不得**返回任何订单字段。

## 限额

- 每 token 默认 **5 次/分钟**（内存计数，演示用）。
- 超限：rate_limited，提示稍后重试；不消耗模型、不写工单。

## 人接什么

工单里带：原问题、分类 intent、token 摘要（不存完整密钥）。人工处理投诉、异常进度、系统故障。
