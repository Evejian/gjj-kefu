## 10 分钟口述（Day12 可当场念）

我们不统一你用哪个 Agent。只统一五件事：

1. 新需求先有规格目录（prd / spec / tasks；想法进 backlog）
2. 完成 = Spec Ready + 测试绿，不许口头 done
3. 密钥只环境变量；**合并权在人**
4. PR 填改动 / 风险 / 怎么测 / Agent 做了什么（手写填「无，人工实现」）
5. CI 绿才能合

禁止：在群里贴长聊天记录当需求。  
本周不做：强制换模型、无门禁自动合并。

## 一周成功线

至少 **1 条需求**走完：规格进仓库 → 测试绿 → **人点合并**。

## 失败态（出现即记一笔，不假装没发生）

- 群里长聊天当需求，未进仓库
- 口头「做完了」，没有 Ready / 测试命令
- 无规格直接合代码
- 密钥进 Git
- Agent 自己合 main（超过自动化等级 1）

## 换壳怎么遵守

不用 Claude 也可以：人写规格、人审 PR、本地跑测试、CI 不依赖 IDE。能合并的条件永远是 **规格在库、测试绿、人点合并**。
