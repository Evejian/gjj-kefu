# PRD · Agent 客服值守（Day8 / L7 适配）

## 用户
缴存职工：既要查政策，也要查「我的贷款办到哪了」；搞不定时要能转人工。

## 场景
在 Day6 主路径之上，加一层 **值守 Agent**：先鉴权与限额，再分意图，政策走 RAG+引用，进度走 Tool，投诉/其它走工单。

## 要解决的问题
1. 只有聊天：模型可能编贷款进度。
2. 只有 RAG：查不了「我的申请」。
3. 无升级路径：低置信与投诉无处去。

## 非目标
- 真微信/真工单系统 / MCP
- 向量库替换关键词检索
- Web UI、多轮记忆

## 成功标准
- `python demo_agent.py` 一次演示：政策引用、订单 Tool、拒答/转人工、限额
- `python test_agent.py` 全绿；`python eval_run.py` 公布评估分数
- 规格见 `docs/spec-agent.md`
