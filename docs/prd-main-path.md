# PRD · 主路径可演示闭环（Day6 / L5 适配）

## 用户
行动营同学 / 评审人：要在 5 分钟内看懂「公积金智能客服」能不能交货，而不是只看到散落脚本。

## 场景
不新开电商仓库（本营主线锁死 gjj-kefu）。把第五课的「交易一根针」映射为本仓库的 **问答一根针**：

| L5 电商 | 本仓库等价 |
|---------|------------|
| 浏览商品 | 输入政策问题 |
| 下单 | 检索 FAQ top3 |
| Mock 支付成功 | 有依据回答（可用 mock，不强制真 key） |
| Mock 支付失败 | 拒答 / 缺 key / API 失败 —— 可提示、可恢复 |
| 订单列表 | 一次跑完多条用例的演示脚本输出 |

## 要解决的问题
1. 主路径仍依赖交互式 `input` + 真 API，新人 / CI / 无密钥时无法一键验收。
2. 成功与失败态没有写成状态机，演示和测试对不齐。

## 非目标
- Web 界面、小程序、真实支付（本营非目标）
- 换电商题做第二个仓库
- 语义检索、多轮对话

## 成功标准
- `python demo_main_path.py` 无交互跑通：成功一次、拒答一次、API 失败一次
- `python test_main_path.py` 全绿
- README 写清 5 分钟路径；密钥仍只走环境变量
