# PRD · 检索优化（top 3 + 打分修正）

## 用户
广州公积金缴存职工，想查个贷政策，需要一个**带政策出处**的可靠回答。

## 场景
用户在 faq_demo.py 里输入一句大白话（如"我能贷多少"），系统从 faq.jsonl 里挑出最相关的几条 FAQ 喂给大模型，回答末尾注明依据的政策文件。

## 要解决的问题
1. 现在检索只取 **top 1**：同一个问题往往和 2~3 条 FAQ 都相关（额度、二孩上浮、绿色建筑上浮），只给模型 1 条参考，回答片面。
2. 打分用原始字符集合重合度：**标点也算分**。"？"几乎每个问句都有，等于白送分，污染排序。

## 非目标（本期不做）
- 语义检索 / embedding
- 多轮对话、Web 界面

## 成功标准
- `python test_retrieve.py` 一键可跑、全绿
- 问"我能贷多少"，回答综合多条相关政策且末尾带出处
- 问完全无关的问题（如"今天天气怎么样"），明确拒答而不是硬编
