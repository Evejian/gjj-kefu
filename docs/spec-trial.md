## 行为规则

1. 只统一 TEAM.md 的五件事；壳可换。
2. 试行周默认 **2026-09-05 ~ 2026-09-11**；结果 9/12 后回写 camp-goals。
3. 失败态必须可观察：群里贴需求、口头 done、无规格合并、密钥进仓、无人点合并。
