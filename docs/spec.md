## 行为规则

1. **打分**：只统计汉字和数字的重合，标点/字母/空白不计入。
2. **排序**：分数相同的条目，保持 faq.jsonl 中的原有顺序（稳定排序）。
3. **拒答阈值**：最高分低于 `MIN_SCORE = 4` 视为检索失败（无相关政策），返回空列表；主程序输出"抱歉，暂时没有查到相关政策"，不调用模型。仅撞一两个常见字（如"怎么"）的弱匹配得 1~3 分，会被拒答（v1 曾设为最高分 0 才拒答，FAQ 扩到 17 条后发现弱匹配污染，2026-08-31 细化为 4）。
4. **prompt 组装**：top 3 全部作为参考资料拼进 system prompt，回答末尾逐条注明来源文件。

## 失败态说明

- FAQ 库为空 / 全部 0 分：主程序拒答，不调用 API（不浪费 token）。
- faq.jsonl 某行格式坏：导入时跳过该行并打印警告（沿用现状即可）。
