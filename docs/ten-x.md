# 10 倍从哪来：我消灭的 5 个重复动作

课程 L3 作业。Harness 装配后，这些动作不再每次靠脑子记和手动做：

| # | 原来的重复动作 | 现在交给谁 | 省在哪 |
|---|---|---|---|
| 1 | 每次开新需求，凭记忆想 PRD 要写啥、漏掉非目标和失败态 | `spec-start` skill | 规格骨架 30 秒出，失败态和"想法进 backlog"不会忘 |
| 2 | 写 commit message 时现想格式，常常只写"更新xx" | `pr-draft` skill | 三段式（改了什么/为什么/怎么验证）自动套，说明永远可验证 |
| 3 | 修 bug 时凭感觉改，改完忘了跑全量测试 | `debug-loop` skill | 不复现不动手、修完必须全绿，肌肉记忆变流程 |
| 4 | 每次收尾靠脑子过一遍"算不算完成" | `/ready` 命令 | 对照 System Ready 清单逐项实测，不许只看代码就说通过 |
| 5 | 担心哪天手滑把密钥提交进仓库（.env / API key） | PreToolUse Hook | 人会忘，Hook 不会。已实测双向：挡 .env，放行正常操作 |

模型路由（flash 调试 / plus 演示，见 CLAUDE.md）另算一层：省钱 + 不限流。

## MCP 说明

按课程原则"不为 MCP 而 MCP"：本项目当前没有需要外部系统接入的真实需求（无工单、无线上库、无设计稿），Python CLI 已覆盖"手"的角色。等主线接入真实数据源（如公积金政策网站抓取）时再评估，已在 backlog 登记。
