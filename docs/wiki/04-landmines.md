# 04 · 雷区与「我仍不敢动」清单

## 已知雷区

1. **打分只认汉字和数字**：英文政策关键词、全角空格异常可能导致意外低分。
2. **MIN_SCORE=4**：只要求 **最高分** ≥4 才返回；top3 里第 2/3 条可以低于 4（当前表征测试已锁）。改过滤策略必须先改测试。
3. **弱匹配**：像「怎么申请」只撞常见字，最高约 3 分 → 拒答。调阈值会改变拒答面。
4. **live 默认模型**：`faq_demo.py` 用 `glm-4-plus`，`answer()` 默认参数是 `glm-4.7-flash`；别混着调却不说明。
5. **`zcwj/` PDF**：扫描件无可靠文本层；不要假设 `pdftotext` 能抽正文。
6. **坏行 FAQ**：当前 `load_faqs` 遇非法 JSON 会直接异常；生产硬化前不要依赖「静默跳过」。
